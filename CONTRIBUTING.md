# Contribuindo com o Refrata

O Refrata é **código aberto, mas não aceita contribuições de código** neste repositório.

## O que é bem-vindo

- **Issues:** relatos de bug, sugestões, ideias e dúvidas. Abra em
  [Issues](https://github.com/LucsLabsStudios/refrata/issues). Todo retorno é lido, e as mudanças
  que fizerem sentido entram numa próxima versão.
- **Forks:** pela licença [GPL 3.0](LICENSE), você pode baixar, estudar, compilar, modificar e
  redistribuir o código, inclusive criar a sua própria versão. Os forks também precisam seguir a
  GPL 3.0 e não podem se apresentar como o Refrata oficial.

## O que não é aceito

**Pull requests.** O projeto é mantido por uma pessoa só, e cada atualização chega
automaticamente a todos que têm o app instalado. Para garantir que nenhum código de origem
desconhecida entre nessas atualizações, todo código do repositório oficial é escrito pelo próprio
mantenedor. Pull requests abertos são fechados automaticamente, com um aviso apontando para as
Issues.

Se você tem uma correção pronta, descreva o problema e a solução numa issue. Ela ajuda do mesmo
jeito.

# Contributing to Refrata

Refrata is **open source, but closed to code contributions** in this repository.

- **Welcome:** issues (bug reports, suggestions, questions) and forks under the GPL 3.0. Forks must
  stay GPL 3.0 and must not present themselves as the official Refrata.
- **Not accepted:** pull requests. The project has a single maintainer and every update reaches all
  installed copies automatically, so all code in the official repository is written by the
  maintainer. Pull requests are closed automatically with a pointer to Issues. If you have a fix,
  describe the problem and the solution in an issue instead.
